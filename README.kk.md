# TeamBuilder AI

[English](README.md) · **Қазақша** · [Русский](README.ru.md)

Студенттерге теңгерімді жобалық команда құруға көмектесетін мобильді қосымша. Студенттер дағдыларын, қызығушылықтарын және бос уақытын көрсетеді, жетекшілер жоба идеяларын жариялайды, ал қосымша ең теңгерімді команданы ұсынып, **әр шешімді түсіндіреді**.

Expo (React Native) және Supabase негізінде жасалған. **Expo Go**-да жұмыс істейді — бөлек құрастыру керек емес. Интерфейс **қазақ, орыс және ағылшын** тілдерінде.

## Мүмкіндіктер

- **Құзыреттер профилі** — рөл, дағдылар, қызығушылықтар, бос уақыт, фото, жетістіктер.
- **Жоба идеялары** — қажетті рөлдер, дағдылар, кездесу уақыты және команда мөлшері көрсетілген идеяны жариялау. Әр жобаның сізге қаншалықты сәйкес екені көрінеді.
- **Өтінімдер және рөлдерді бөлу** — студент рөлге өтінім жібереді, жетекші қабылдайды не бас тартады және кейін рөлді ауыстыра алады.
- **Команданы автоматты құру** — қосымша барлық мүмкін құрамдарды тексеріп, ең теңгерімді 3 нұсқаны балымен, критерийлер бойынша бөлінісімен және әр шешімнің себебімен ұсынады.
- **Тапсырмалар және жеке үлес** — ұпайы бар тапсырмалар тақтасы (жасау керек → процесте → дайын) және мүшелердің бір-бірін бағалауы (1–5 ★). Екеуінен *үлес индексі* есептеледі.
- **Чаттар** — жоба чаттары және жеке хаттар, тірі жаңартумен.
- **Кампус жаңалықтары (REST API)** — үш тілдегі хабарландырулар өз REST API-мізден `fetch` арқылы алынады: жүктеу, қате, бос тізім, интернетсіз кэш, төмен тартып жаңарту.
- **Таңдаулылар (SQLite)** — жаңалықты офлайн сақтау, «оқылды» белгісі, сүзгі, іздеу және жою; интернетсіз жұмыс істейді.
- **Іс-шараға тіркелу** — әр өрісі тексерілетін форма (аты-жөні, топ, телефон, email, нақты болашақ күн, 1–5 қатысушы, келісім).
- **Поштаға келген кодпен кіру** — құпиясөзсіз, кіру есте сақталады.

## Команда қалай құрылады

`src/utils/matching.ts`

1. Әр студентке жобаға қатысты жеке балл беріледі (рөл, дағды, уақыт, қызығушылық). Ең жақсы 12 адам үміткерлер тізіміне енеді.
2. Бос орындарға үміткерлердің **барлық комбинациялары** тексеріледі — «ең мықтыны бір-бірден» емес.
3. Әр құрам тұтас бағаланады:

   | Критерий | Салмағы |
   |---|---|
   | Рөлдер теңгерімі (керек рөлдер жабылған, қайталау жоқ) | 35% |
   | Дағдыларды жабу | 30% |
   | Бәріне ортақ бос уақыт | 25% |
   | Ортақ қызығушылықтар | 10% |

   Басқа жобада бос емес студентке айып балл қойылады.
4. Ең жақсы 3 құрам көрсетіледі. Түсіндірмелер «егер…» тексерісінен шығады: мүшені алып тастау («онсыз команда балы 16-ға төмендейді») немесе үміткерді біреудің орнына қою («Дамир орнына қойсақ, балл 89 → 81 төмендейді»).

**Үлес индексі** (`src/components/ContributionTab.tsx`) = 60% орындалған тапсырмалар ұпайы + 40% командадағылардың орташа бағасы.

## Іске қосу

**Керек:** Node.js 22.13+ (немесе 24.3+), телефонда **Expo Go**-ның соңғы нұсқасы және тегін [Supabase](https://supabase.com) жобасы.

```bash
git clone <репозиторий сілтемесі>
cd TeamBuilder
npm install
cp .env.example .env      # Supabase URL мен publishable кілтін жазыңыз
npx expo start
```

QR-кодты Expo Go арқылы сканерлеңіз.

### Supabase баптау

1. Жоба ашыңыз. **Project Settings → API Keys** бөлімінен **Project URL** мен **publishable** кілтін `.env`-ке көшіріңіз. Құпия кілтті қосымшаға салмаңыз.
2. **SQL Editor**-да ретімен орындаңыз: `supabase/schema.sql`, `supabase/storage.sql`, `supabase/ratings.sql`.
3. Демо деректер (қаласаңыз): қосымшаға бір рет кіріп, сосын `supabase/seed.sql` (17 тест студент, екі жоба, өтінімдер) және `supabase/i18n_news.sql` (кампус жаңалықтары мен демо деректердің аудармалары) орындаңыз. Бірінші тіркелген пайдаланушы демо жобаның жетекшісі болады.
4. **Поштаға код:** **Authentication → Emails** бөлімінде өз SMTP-іңізді қосыңыз (мысалы, қолданба құпиясөзі бар Gmail), сосын **Confirm sign up** және **Magic link or OTP** үлгілерінде кодты `{{ .Token }}` арқылы шығарыңыз.

## Қауіпсіздік

Барлық деректер Supabase-те Row Level Security ережелерімен қорғалған:

- профильдер мен жобаларды барлық кірген адам көреді, бірақ тек өзініңкін өзгерте алады;
- өтінімді қабылдау мен рөлді ауыстыру — тек жетекшіде;
- тапсырмаларды, жоба чатын және бағаларды тек команда мүшелері көреді;
- жеке хатты тек екі әңгімелесуші көреді;
- фотоны тек өз бумаңызға жүктей аласыз (тек сурет, 2 МБ-қа дейін).
