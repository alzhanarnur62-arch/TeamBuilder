# TeamBuilder AI

[English](README.md) · [Қазақша](README.kk.md) · **Русский**

Мобильное приложение, которое помогает студентам собирать сбалансированные проектные команды. Студенты указывают навыки, интересы и свободное время, руководители публикуют идеи проектов, а приложение предлагает самую сбалансированную команду и **объясняет каждое решение**.

Сделано на Expo (React Native) и Supabase. Работает в **Expo Go** — отдельная сборка не нужна. Интерфейс на **казахском, русском и английском**.

## Возможности

- **Профиль компетенций** — роль, навыки, интересы, свободное время, фото, достижения.
- **Идеи проектов** — публикация идеи с нужными ролями, навыками, временем встреч и размером команды. У каждого проекта видно, насколько он подходит именно вам.
- **Заявки и роли** — студент подаёт заявку на роль, руководитель принимает или отклоняет её и может позже сменить роль.
- **Автоподбор команды** — приложение перебирает все возможные составы и предлагает 3 самых сбалансированных: с оценкой, разбивкой по критериям и причинами каждого решения.
- **Задачи и личный вклад** — доска задач (сделать → в работе → готово) с баллами и взаимная оценка участников (1–5 ★). Из них считается *индекс вклада*.
- **Чаты** — чаты проектов и личные сообщения в реальном времени.
- **Новости кампуса (REST API)** — объявления на трёх языках через `fetch` из собственного REST API: загрузка, ошибка, пустой список, кэш без интернета, обновление потягиванием вниз.
- **Избранное (SQLite)** — сохранение новостей офлайн, отметка «прочитано», фильтр, поиск и удаление; работает без интернета.
- **Регистрация на мероприятие** — форма с проверкой каждого поля (имя, группа, телефон, email, реальная будущая дата, 1–5 участников, согласие).
- **Вход по коду из письма** — без паролей, вход запоминается.

## Как работает подбор команды

`src/utils/matching.ts`

1. Каждый студент получает личный балл относительно проекта (роль, навыки, время, интересы). 12 лучших попадают в список кандидатов.
2. Проверяются **все комбинации** кандидатов на свободные места, а не «лучший по одному».
3. Каждый состав оценивается целиком:

   | Критерий | Вес |
   |---|---|
   | Баланс ролей (нужные роли закрыты, нет повторов) | 35% |
   | Покрытие навыков | 30% |
   | Общее свободное время | 25% |
   | Общие интересы | 10% |

   За студентов, уже занятых в другом проекте, снимается штраф.
4. Показываются 3 лучших состава. Объяснения строятся проверкой «что если»: убрать участника («без него оценка упадёт на 16») или поставить кандидата на чужое место («если поставить вместо Дамира, оценка упадёт: 89 → 81»).

**Индекс вклада** (`src/components/ContributionTab.tsx`) = 60% баллы за выполненные задачи + 40% средняя оценка от команды.

## Запуск

**Нужно:** Node.js 22.13+ (или 24.3+), последняя версия **Expo Go** на телефоне и бесплатный проект [Supabase](https://supabase.com).

```bash
git clone <ссылка на репозиторий>
cd TeamBuilder
npm install
cp .env.example .env      # и впишите URL и publishable-ключ своего Supabase
npx expo start
```

Отсканируйте QR-код в Expo Go.

### Настройка Supabase

1. Создайте проект. В **Project Settings → API Keys** скопируйте **Project URL** и **publishable**-ключ в `.env`. Секретный ключ в приложение не кладите.
2. В **SQL Editor** выполните по порядку: `supabase/schema.sql`, `supabase/storage.sql`, `supabase/ratings.sql`.
3. Демо-данные (по желанию): один раз войдите в приложение, затем выполните `supabase/seed.sql` — 17 тестовых студентов, два проекта, заявки — и `supabase/i18n_news.sql` — новости кампуса и переводы демо-данных. Первый зарегистрированный пользователь станет руководителем демо-проекта.
4. **Коды на почту:** в **Authentication → Emails** подключите свой SMTP (например, Gmail с паролем приложения), затем в шаблонах **Confirm sign up** и **Magic link or OTP** выведите код через `{{ .Token }}`.

## Безопасность

Все данные в Supabase защищены правилами Row Level Security:

- профили и проекты видят все вошедшие, но менять можно только своё;
- принимать заявки и менять роли может только руководитель;
- задачи, чат проекта и оценки видят только участники команды;
- личные сообщения видят только двое собеседников;
- фото можно загружать только в свою папку (только картинки, до 2 МБ).
